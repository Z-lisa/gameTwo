# gameTwo
这是一个基于 HTML5 Canvas 开发极简风格 2D 音游
《节奏大师》- 音乐节奏游戏

游戏简介：

《节奏大师》是一款充满动感的音乐节奏游戏，玩家需要跟随音乐节拍，在音符到达判定线的瞬间按下对应按键来获得分数。

✨ 游戏特色：

- 🎵 三种难度模式 ：简单🌱、普通⚡、困难🔥，适合不同水平的玩家
- 🎹 多轨下落式音符 ：四通道彩色音符，带来丰富的视觉体验
- ⭐ 精准判定系统 ：Perfect/Great/Good/Miss 四级判定，挑战你的节奏感
- 🔥 连击加分机制 ：连续命中可获得额外分数加成，5连击以上触发特效
- 📊 详细数据统计 ：准确率、最高连击、命中分布一目了然
- 🏆 评级系统 ：S/A/B/C/D 五级评级，追求完美表现
- 📱 全平台支持 ：键盘、触屏、虚拟按键，随时随地畅玩
🎯 操作方式：

- 键盘 ：D/F/J/K 对应四轨，空格键通用判定
- 触屏 ：点击屏幕任意位置或底部虚拟按键
- 快捷键 ：ESC/P 暂停，R 重置，Q 退出
🎨 视觉体验：

- 炫酷粒子特效，击中音符时的爆炸效果
- 彩色渐变界面，流畅动画过渡
- 响应式设计，完美适配各种设备
